SETUP & CONTROL

Before you connect.

Can Gallium use my existing login?

Yes, for configured workflows. Install the bridge in your Chrome profile and enable it on the relevant tab. A procedure defines the account, allowed actions, and result to check.

Can Gallium explore an unfamiliar site?

Gallium can read public HTTPS documents and follow supported controls with a configured model router. Exploration stays on the same origin, has a time limit, and stops at sign-in and challenge pages.

Can I take over partway through a task?

Yes. Pause the operation’s scope to take control. The pause survives a restart. Hand control back explicitly when you’re ready.

Can I try it before connecting Chrome?

Yes. Run the local fixture demo with Node 24 or later. It demonstrates a verified save, duplicate prevention, and human handoff.
