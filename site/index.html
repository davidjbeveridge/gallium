VERIFICATION

A click is only
half the job.

Ask for a fact and get a passage you can check. For a configured change, Gallium reads back the new state before it reports success.

A site can accept a click without saving the change. If Gallium cannot confirm a write, it checks before retrying. The same operation ID helps it avoid repeating completed work.

Before you connect.

Can Gallium use my existing Chrome login?

Yes, for configured workflows. You install the bridge in your Chrome profile and enable it on the relevant tab. A procedure defines the account, actions, and result to check. Chrome setup is a separate step from the CLI install.

Can it work on an unfamiliar website?

Gallium can read public HTTPS documents and follow supported controls on unfamiliar public sites with a configured model router. Exploration has a time limit, stays on the same origin, and stops at sign-in or challenge pages. Account actions and writes need a configured procedure.

How is it different from a browser automation library?

Gallium accepts a task through MCP or the CLI. It can use a direct request or browser interaction, checks the outcome for configured writes, and keeps track of who controls the browser. A browser automation library gives developers primitives for scripting the browser.
