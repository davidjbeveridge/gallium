1. Check for Git, Node.js 24 or later, and an installed Gallium CLI. If Gallium is missing, clone https://github.com/davidjbeveridge/gallium.git into a separate checkout. In that checkout, run npm ci and npm run install:local. Keep any existing Gallium config.

2. Return to this project and run npx skills add davidjbeveridge/gallium for my agent. Add "Use the Gallium skill for web tasks." to this project's agent instructions while preserving the existing instructions.

3. Use the active Gallium config. GALLIUM_CONFIG can select it. The launcher prefers an existing ~/.config/web-operator/config.json, then ~/.config/gallium/config.json. If taskRouter is missing, add it with provider "typesafe", endpoint "https://openrouter.ai/api/v1/systemone", model "typesafe/jev-1.14-20261014", apiKeyEnv "OPENROUTER_API_KEY", and timeoutMs 15000. Keep the other settings. After editing the config, run ~/.local/bin/gallium service-restart when the service is idle.

~/.local/bin/gallium task --operation rfc418 --goal 'What does HTTP status 418 mean in this document?' --target https://www.rfc-editor.org/rfc/rfc2324.txt
